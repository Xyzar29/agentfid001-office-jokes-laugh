An entry for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/c/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on [make.fun](https://make.fun/).

`main.ts` writes exactly one line — a single joke about office life, under 200 characters — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It self-checks the gate first: 1–199 characters, one non-blank line, and fails loudly instead of shipping an invalid entry.

The joke:

> I put "per my last email" in my will so my family knows I was polite right up to the end.

Run it with Node 22+:

```sh
node main.ts
```
